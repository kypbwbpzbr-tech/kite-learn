# 🪁 风筝学堂 - 智能学习平台

> 放飞知识的风筝，让学习更有趣

K9全科智能学习平台，知识图谱+AI出题+必背内容+风筝积分系统

## ✨ 功能特性

### 核心学习功能
- 🗺️ **知识图谱** - 可视化展示知识点关系，哪里不会学哪里
- 📚 **必背内容** - 数学公式、定理定义，背诵赚取风筝币
- 🤖 **AI智能出题** - 根据知识点和掌握程度，自动生成练习题
- ❌ **错题本** - 自动收录错题，支持艾宾浩斯复习法
- 📅 **学习计划表** - 可打印的周/日计划表

### 积分与成就
- 🪁 **风筝积分系统** - 学习赚风筝币，升级解锁权益
- 🎯 **每日目标** - 设定每日学习目标，追踪完成进度
- 🏆 **成就系统** - 解锁各种成就，记录学习里程碑

### 辅助功能
- ⭐ **我的收藏** - 收藏重要内容，随时查看
- 📅 **学习日历** - 可视化学习记录，坚持打卡
- 📄 **PDF导出** - 学习计划一键导出打印

### 体验优化
- 📐 **数学公式** - KaTeX渲染，清晰展示数学公式
- 🎨 **米白色背景** - 护眼温暖的学习环境
- 🪁 **风筝主题** - 清新可爱的视觉风格
- ✨ **流畅动画** - 页面切换、交互反馈动画
- 📱 **响应式设计** - 手机、平板、电脑完美适配

## 🚀 快速开始


### 2. 启动开发服务器

```bash

```

- 📖 复习错题：+15 风筝币
- 🏆 完成章节：+50 风筝币

## 📅 错题本特色

### 艾宾浩斯复习法

错题本采用科学的艾宾浩斯遗忘曲线，帮助你高效复习：

- 第1次复习：1天后
- 第2次复习：3天后
- 第3次复习：7天后
- 第4次复习：14天后
- 第5次复习：30天后

复习5次后自动标记为"已掌握"。

### 统计分析

- 错题总数、待复习、已掌握统计
- 题型分布（选择、填空、判断）
- 难度分布（简单、中等、困难）
- 掌握度进度条
